# Docker 镜像使用说明

本目录包含 1.1.0 版数据库、后端和前端三份离线镜像，以及使用相对路径和环境变量的启动配置。无需修改任何源码或宿主机路径。

## 使用步骤

1. 启动 Docker Desktop。
2. 在本目录执行 `.\load-images.ps1`。
3. 复制 `.env.example` 为 `.env`。
4. 在 `.env` 中填写两个独立的数据库强密码和模型 API Key；端口可保持默认值。
5. 执行 `.\start.ps1`。
6. 浏览器打开 `http://127.0.0.1:18080`。
7. 可执行 `.\smoke-test.ps1` 检查首页、会话入口、5 道岗前测评、数据行数和只读权限。

停止服务：

```powershell
.\stop.ps1
```

如需同时清空本机 Docker 数据卷并重新导入比赛数据：

```powershell
.\stop.ps1 -RemoveData
```

## 配置边界

- `.env.example` 只有占位值，不含真实账号、密码或 API Key。
- `docker-compose.yml` 不挂载宿主源码、数据库目录或前端构建目录。
- 数据库在首次创建命名卷时自动导入 5 个 CSV，并将 `ref_reader` 收敛为只读权限。
- 后端在配置模型 API Key 后运行真实交互链；未通过审核或查询安全检查的内容会安全停止。
- 三个服务仅绑定本机回环地址。

`SHA256SUMS.txt` 仅用于校验三份镜像 tar 的传输完整性，不属于源码包内容。
