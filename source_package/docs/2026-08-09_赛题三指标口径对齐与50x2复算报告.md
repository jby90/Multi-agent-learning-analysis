# 赛题三指标口径对齐与正式 50×2 复算报告

## 一、结论

本次没有降低金标，也没有修改生产工作流、正式 50 例、21 条状态转移、R-01～R-06 或创新 A+B。修复内容仅是把此前混用的两个“适配”概念拆开：

1. **赛题核心指标：学员画像—资源难度适配准确率**，门槛为 `≥85%`；
2. **创新诊断指标：动态有效调整率**，观察真实交互后是否发生必要的路径、难度、任务复杂度或追问变化，不设置赛题门槛。

## 二、指标定义

| 层级 | 指标 | 计算口径 |
|---|---|---|
| 赛题核心 | 最终发布幻觉率 | 最终批准发布且判定为事实性幻觉的内容单元 / 最终发布事实单元；同一单元命中多条规则只计 1 次 |
| 赛题核心 | 学员画像—资源难度适配准确率 | 正式会话中，画像诊断后的知识点、初始难度、路由证据和实际下游资源全部命中冻结金标的会话 / 全部正式会话 |
| 赛题核心 | 核心知识点完整闭环覆盖率 | 同时满足三档难度、讲义—实操—分阶测验—反馈闭环、Learning Contract 与岗位画像精准匹配的核心知识点 / 10 |
| 创新诊断 | 动态有效调整率 | 真实交互后实际改变路径、难度、任务复杂度或追问的有效节点 / 全部需适配节点；正确 `keep` 可审计但不计分子 |
| 辅助 | 幻觉拦截率 | 首次生成错误且被自动阻断的内容谱系 / 首次生成错误内容谱系 |
| 辅助 | 原生教学适配失配率 | 首轮经 R-03 确认失配的生成事务 / 首次 R-03 审核事务；低为好 |

## 五、适配准确率的严格门禁

单个正式会话只有同时满足以下条件才计为适配准确：

1. 使用真实 `production` 路由；
2. 诊断事件与节点绑定有效；
3. 所选知识点及初始难度命中独立冻结金标；
4. `knowledge_point_plan` 具备真实证据 ID 和路由理由；
5. 实际生成下游学习资源，且其难度与预期一致。

这不是把 `keep` 改名、扩大分子或降低标准；它直接对应赛题“学员画像—资源难度适配准确率”的要求。
