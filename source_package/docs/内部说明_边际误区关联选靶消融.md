# 边际误区关联选靶消融（内部说明）

## 目的与边界

本消融比较同一冻结代码中的两种内部路由策略：

- B0 `total_support`：沿用总知识点支持数、切片支持数和领域顺序；
- B1 `marginal_support`：优先尚未被批准关系追问使用的支持点，只保留正边际增益候选。

它验证路由的可复算控制性质，不验证真实学员成绩或教学效果。专业人员抽检不属于采用硬门禁。

- 正式领域资产与正式 `T-02`，责任范围为“完成率计算、计划量与实际量口径”；
- 完全相同的固定 answer-diagnosis 历史、轮次、诊断、probed 和 covered；
- 覆盖只能来自此前由 `fixed-evidence-bound-review-v1` 批准、证据绑定并完成后端提交的 M-01→M-04；
- 不接受命令行临时关系、任意 covered 集合、monkeypatch 或分叉后 LLM 输出。
