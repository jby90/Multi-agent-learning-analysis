进阶层不只是"看出上下游有时间对应"，而是**做完整的传导归因**：从下游的异常出发，沿工序依赖链往上溯源，找到候选源头，并判断整条链到底是链式传导、疑似传导、证据不足，还是混合异常。

## 1. 溯源分析链

从一个下游工序的异常出发，按以下顺序分析：

- **定位现象**：确认下游工序在某月出现明显异常；
- **沿依赖链上溯**：查它的上游工序在更早或同期是否也异常，逐级往上，找到最早出现异常的工序月份，作为**候选源头**（最早出现异常只能确定候选，可能受报工、计划版本或共同因素影响，需再核验）；
- **核对时序与齐套暴露**：候选源头在逻辑时间上领先于下游，且下游确实暴露于交付或齐套缺口，才支持传导；
- **排查共同原因和下游局部原因**：确认多工序异常不是由共同外部因素（如整体计划调整）造成，也确认下游没有自身独立的局部异常。

## 2. 传导强度不预设方向

异常沿工序链传导时，强度不是必然逐级减弱。下游异常相对上游，可能**收窄、近似保持、扩大，或与下游本地问题叠加**，取决于在制缓冲是否耗尽、齐套门槛、是否存在瓶颈工序、干预补偿（加班/调序/资源增援）、计划基数差异或多项缺料同时发生。**强度形态不是传导成立的必要条件。** 因此：

- 观察异常强度沿链的变化，但不预设它一定衰减；
- **下游异常比上游更重时，不能直接判为独立异常**——应核查齐套门槛、瓶颈放大、计划基数效应（分母不同使偏差率放大或收窄）和下游本地叠加，而不是简单归因。

## 3. 结论分四态

传导判断不是"是/否"二分，应按证据分四态输出：

- **支持传导**：存在明确工序依赖路径、上游异常在逻辑时间上领先、且下游确实暴露于交付或齐套缺口；
- **疑似传导**：仅有完成率序列的时间对应，缺齐套/交接证据，只能标记为疑似；
- **证据不足**：时序、依赖或齐套证据不完整，无法判断；
- **混合异常**：既有上游传导证据，又有下游本地独立异常。

## 4. 数据支持的边界

基于工序×月份的完成率序列，数据可以支持：

- 哪道工序哪个月最早、最明显地出现异常（候选源头）；
- 上下游异常在时序上是否呈"上游领先"的对应；
- 异常强度沿链的变化形态（吸收/保持/放大/叠加）。

数据通常不能单独支持：

- **确认因果**：完成率的时序对应只是"疑似传导"，真正证明"上游异常导致下游缺料"，需要物料流转、齐套状态、投料交接等现场证据；
- **候选源头的根本原因**：源头工序为什么异常（产能、物资、计划、报工），需其他字段与现场核验；
- **责任归属**：需核验设计、物资、前序交付等条件。

因此进阶结论应写成"时序与依赖形态支持疑似传导，候选源头疑为某工序某月，尚需齐套与交接证据确认"，而不是直接下"上游导致下游、由上游负责"的判断。

## 5. 常见误区

1. 只看下游异常就地处理，不沿工序依赖链上溯，漏掉候选源头。
2. 见"多工序都异常"就判传导，不核对依赖路径、时序领先与齐套暴露，也不排查共同原因。
3. 把最早异常点直接当成确定源头，不再核验其与下游工作包、物量交接和齐套关系。
4. 预设逐级衰减，见下游比上游更重就判独立异常，忽略传导放大与叠加的可能。
5. 把完成率序列的时序对应当成已证明的因果，不留"需齐套/交接证据确认"的余地，也不用"证据不足/混合异常"标注不确定的情形。
