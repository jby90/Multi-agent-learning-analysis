进阶层要面对时滞时序筛查真正的难点：**时滞不确定、且月度数据本身会制造伪时滞**。窗口内看到下游偏离，可能是上游的滞后响应，也可能是月度口径造成的假象。进阶层要能甄别这些陷阱、把证据缺口写清，并把结果作为**四态候选交给传导关系知识点最终核验**，而不是自己定案。

## 1. 时滞不确定带来的三类陷阱

- **窗口取窄漏判**：把候选窗口锁死单期，响应若来得更晚就被漏判，误得"未传导"。
- **窗口取宽误纳**：窗口无依据地放宽时，下游任何偏离都可能被硬套成"上游响应"，误纳巧合。
- **多重信号叠加**：窗口内下游出现多次偏离，难分哪次是上游响应、哪次是本地问题——核验时**不要只看幅度，应优先核对具体工作包、托盘或物量交接关系**，逐一甄别。

## 2. 月度数据的两类伪时滞（必须先排除）

月度脱敏序列最容易产生两类"表面时滞"，它们不是真传导：

- **对象链错配**：同船、同工序、相邻月份，**不代表对应同一批工作包、托盘或物料**；把不同批物量的相邻期偏离当成传导，是错配。
- **统计时点错位**：实物完工、车间报工、质检确认和工作包关闭可能跨月发生，形成表面上的时滞，实为统计时点不一致造成的口径假象。

发现候选响应后，先排除这两类，才谈时序相容。

## 3. 输出四态候选，最终由传导关系知识点核验

时滞分析的结论落到传导判断的四态（支持传导／疑似传导／证据不足／混合异常，见三道工序与传导关系），但**本节只给"四态候选"，最终判定按传导关系知识点核验**：

- 时序相容 + 窗口有依据、且已排除伪时滞 → 候选"疑似传导"，待依赖/齐套核验；
- **已确认下游未暴露于该上游缺口 → 不支持该传导路径；尚未取得齐套或交接数据 → 归为证据不足**（区分"确认没暴露"与"没取得数据"）；
- 窗口/时序证据不完整 → 证据不足；
- 既有上游滞后响应、又有下游本地独立异常 → 候选"混合异常"。

进阶结论应写成"下游某期偏离与上游异常在候选窗口内时序相容，已排除对象错配与统计时点错位，列为疑似传导候选，候选上游为某工序某月，尚需依赖与齐套证据由传导关系知识点确认"，而不是"上游经一个月传导导致下游、由上游负责"。

## 4. 数据支持的边界

基于工序×月份序列，时滞分析只能回答：**哪些上下游期间在时间上相容**（候选响应期、时序支持程度、窗口依据、证据缺口）。

它不能回答：**是否由其造成**（那需依赖链、工作包/物量对应、齐套暴露、交接记录，由传导关系知识点结合现场证据判定）；也不能确定精确时滞值（示例只给候选起点，非普适常数）；不涉及责任归属。一句话：**时滞分析只回答"哪些上下游期间在时间上相容"，不回答"是否由其造成"。**

## 5. 常见误区

1. 把候选窗口锁死单期或无依据放宽，漏判或误纳。
2. 不先排除对象链错配与统计时点错位，把月度口径假象当成真时滞。
3. 多重信号只看幅度，不核对工作包/托盘/物量交接。
4. 把"没取得齐套数据"当成"确认未暴露"，据此错误排除传导路径。
5. 在本节就直接判四态定案，越过传导关系知识点的依赖/齐套/现场核验。
6. 把示例的相邻期对应当成精确时滞常数对外声称。
