进阶层要面对执行单元定位最容易被误用的地方：**定位到某单元数字差，被直接当成"该单元的责任"**。进阶层要能区分这个单元的异常属于哪类候选成因，并把定位结果作为**线索**交给归因与传导判断，而不是自己下"该单元负责"的结论。

## 1. 定位到单元后的五类候选成因

同样是"异常集中于某执行单元"，成因候选可分为：

- **本地执行约束**：该单元自身的产能、设备、人员、质量等生产执行问题；
- **上游缺口暴露**：上游工序缺料/欠产传导到本单元，本单元只是承接缺口的**落点**，非源头（详见三道工序与传导关系、传导时滞分析）；
- **共性条件影响**：整体计划调整、共同物资短缺等落在该单元——**异常可能并非由该单元可控因素主导**；
- **报工或口径待核**：报工滞后/补报/冲销、完工认定或口径不一致造成的表观异常（这是数据/状态确认问题，不是生产执行根因，须与本地执行约束区分）；
- **混合情形**：以上并存（如本地执行约束 + 承接上游缺口）。

**数字上"集中于某单元"这几类都可能，不能仅凭定位判成因。**

## 2. 区分候选成因的核验

- **看上游**：不能只看上游同期或更早是否异常，还要**核对是否属于同一工作包、托盘或物量依赖路径，以及该单元是否实际暴露于上游交付或齐套缺口**——是，则可能是上游缺口暴露的落点而非源头（交传导判断）；
- **看共性条件**：其他单元、其他工序是否同期受同一外部因素影响；
- **看报工口径**：先排除报工滞后/补报/认定时点造成的表观异常；
- **看本地证据**：该单元是否有独立的设备/质量/物资异常证据——有才支持本地执行约束。

几类可能并存，此时是混合情形，分别标记。

## 3. 定位是线索，责任不由定位定

产出是"异常集中于某单元，成因候选为本地执行约束／上游缺口暴露／共性条件／报工待核／混合"。

它不回答责任归属——定位到落点单元不等于该单元负责；若是上游缺口暴露，责任线索指向上游而非落点；责任判定需结合传导证据（见三道工序与传导关系）、归因方法与现场证据。进阶结论写成"异常集中于某单元，成因候选为某（如上游缺口暴露落点，待传导判断确认），不据此直接判该单元责任"。

## 4. 数据支持的边界

基于按执行单元下钻的序列，本节能支持：异常在各单元间集中还是分散、集中于哪个单元、该集中可能由哪类候选成因解释。

它不能支持：确认成因（需归因与传导判断）；责任归属（需传导证据与现场证据）；跨工序的责任传递（跨工序归因方法的范畴）。定位只把范围收窄到单元，把成因与责任交给后续。

## 5. 常见误区

1. 把"定位到某单元"直接判成"该单元的责任"，忽略上游缺口暴露与共性条件。
2. 见集中于某单元就断定本地执行约束，不核上游、共性条件与报工口径。
3. 把承接上游缺口的落点单元当成源头，责任指错方向。
4. 把报工/口径造成的表观异常当成本地执行根因，两类不分。
5. 在本节就下责任归属结论，越过传导证据与现场证据核验。
