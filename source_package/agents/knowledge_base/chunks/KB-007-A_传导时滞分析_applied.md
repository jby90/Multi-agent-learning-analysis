基础层知道"上下游影响可能存在时滞，不能只用同月数据确认或排除传导"；应用层要**在候选窗口内对齐上下游序列，输出候选响应期与时序相容性**——本节只做时序筛查，提供线索，不自行判定是否构成传导。核心难点：时滞不是固定常数，窗口要有依据、不能任意扩。

## 1. 不建立固定传导周期

上游异常传到下游需要时间，因为装配依赖、有限在制缓冲和动态计划衔接的存在，时滞本来就不是固定常数。**本数据的已核验示例中，上游异常与下游疑似响应落在相邻统计期；但这仅表示月度序列上的相邻期对应，不等同于实际传导时长固定为一个月，也不作为其他船号、工序或数据集的固定参数。** 示例只用于确定候选查找的起点，不建立传导周期。

## 2. 在有依据的候选窗口内对齐序列

发现上游某月异常后，按以下做法找下游候选响应：

- **构造工序×月份对照表**：把上下游工序的月度序列并排，便于按时间错位比对。
- **在候选窗口内检查**：检查同月不可分辨区间及后续期间。**窗口应依据工序计划衔接、在制缓冲或历史交接记录设置；缺乏依据时，结果标记为探索性**，不任意扩窗。
- **同月不能只作即时或排除判断**：月度数据无法分辨月内先后——同月正常不能排除后续影响；同月同时异常也不能仅凭月度数据确认即时传导。

## 3. 本节只输出时序证据

在候选窗口内对齐后，本节的产出限于**时序层面的证据**：

- 候选源头期、候选响应期；
- 时序是否相容（下游候选响应是否落在上游异常的合理候选窗口内）；
- 窗口设置的依据、是否存在多个候选、以及证据缺口。

**本节不判定传导是否成立**。是否构成传导，须由传导关系知识点结合依赖链、工作包或物量对应、齐套暴露、交接记录、共同因素与下游本地异常综合判定（详见三道工序与传导关系）。

## 4. 常见误区

1. 在上游异常当月查下游、见正常就断言"未受影响"，忽略后续期可能的响应。
2. 反过来把同月同时异常直接当即时传导，月度数据分不出月内先后。
3. 把时滞当固定一个月写死，或把单个示例的相邻期对应泛化成普适时滞。
4. 候选窗口无依据地任意扩大，把下游任意偏离都纳入，误纳巧合。
5. 在本节就直接判"传导成立"，越过物量、齐套与现场核验（那是传导关系知识点的职责）。
