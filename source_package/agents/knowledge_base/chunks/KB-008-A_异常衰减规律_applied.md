基础层知道"强度沿链不预设方向、衰减只是一种形态"；应用层要**在完成对象匹配、时滞对齐和口径核验之后，比较上下游欠产强度，只描述表观形态（收窄/近似保持/扩大/不可比）**，不把数值形态直接解释成缓冲、放大或叠加等业务机制。

## 1. 先对齐，再比强度

比较前必须先满足：上下游属于同一对象链（同批工作包/托盘/物量），已按时滞对齐（上游期对下游期），聚合口径与计量单位一致。任一不满足，形态判为**不可比**，不进入强度比较。

分析只针对欠产侧：强度可用 `shortfall_intensity = GREATEST(-deviation_rate, 0)`（只取欠产、超产记录另行处理），避免直接比"完成率高低"造成方向混乱。

## 2. 只描述表观数值形态

对齐后比较上下游欠产强度，得到表观形态（**只是数字变化，不是机制结论**）：

- **表观收窄**：对齐后下游欠产偏差小于上游；
- **近似保持**：上下游强度差落在项目配置的容差范围内；无既定阈值时，直接报告差值，不自行制定行业阈值；
- **表观扩大**：下游相对偏差更大；
- **不可比**：对象/口径/时滞未对齐。

**表观形态不等于业务机制**：表观收窄不证明是缓冲吸收，表观扩大不证明是真放大。

## 3. 机制需另行核验（不在本节下结论）

数值形态之外的原因解释——缓冲吸收、资源补偿、门槛放大、本地叠加、证据不足——**需结合在制缓冲、齐套、赶工、计划版本核验**，不能由数字直接推断：

- 表观收窄是否属实际吸收，需核在制缓冲、齐套、赶工及计划版本（单纯下调计划基线不算吸收）；
- 表观扩大需排查齐套门槛、瓶颈、本地异常及**分母基数差异**（计划基数不同会使偏差率放大或收窄）。

## 4. 影响范围只到可观察节点

若确为收窄形态，只能写"欠产偏差收窄若干个百分点"；**百分点收窄不等于实物缺口减少**——只有上下游物量单位一致、对象一一对应时，才可进一步讨论实物缺口减少量。

影响范围记录为"异常信号在对齐序列中可观察到的最远下游节点"；真实影响边界仍需工作包、物量交接和齐套证据确认，不能假设"越往下游一定越轻"。

## 5. 常见误区

1. 不先做对象匹配/时滞对齐/口径核验就比强度，得出不可比的伪形态。
2. 把表观收窄直接判为缓冲吸收、把表观扩大直接判为真放大，跳过机制核验。
3. "近似保持"自行拍阈值，而非用项目容差或直接报差值。
4. 把百分点收窄当成实物缺口减少，忽略单位/对象一致性前提。
5. 用完成率高低直接比强度，不用欠产强度口径，方向混乱。
