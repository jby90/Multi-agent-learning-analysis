基础层掌握"低于正常区间下限即异常信号"；应用层要**避免把单条信号直接当结论**——一个偏低的月度完成率，可能是真异常，也可能是正常波动或数据口径造成的假象。应用层的任务是综合多条线索作出更可靠的判定。

## 1. 单点信号不足以定性

单月完成率偏低只是**信号**，不是结论。是否构成异常，要结合：

- **偏差幅度与影响**：偏离下限越远、影响越大，越难用正常波动解释；单期显著偏差即使不持续也可能需要立即关注。
- **持续性**：连续多月走低更可能是形成趋势。持续性用于判断是否形成趋势，**不是异常成立的必要条件**——单期重大偏差同样可以成立。
- **独立佐证**：延误、齐套、质量、报工状态、关键节点或现场记录等与完成率**不同源**的信息是否同向。（注意：风险等级由偏差率分档生成，与完成率异常同源，仅用于分档和优先级提示，**不增加异常证据的独立性**。）

## 2. 多工序线索的联合核查

同一船号的多个工序同时或相邻期出现偏离时，**可分别标记异常信号**，但应联合核查共同口径、计划因素、共同外部因素及上下游关联，避免孤立地下原因或责任结论。同步偏离时重点检查共同因素；出现上游在前、下游在后的时序形态时，转入传导相关知识点进一步分析。**本节只发现"需要联合核查"，不确认传导因果。**

## 3. 真异常与假异常（非生产性差异）的初步区分

判定前先排除"非生产性差异"——即可由数据、口径、报工或计划解释的偏低，它不是生产异常：

- **口径错位**：聚合、周期、单位或对象范围错位，会让正常数据显示为偏低（详见月度聚合方法）。
- **计划错配**：计划版本或计划对象错配造成的偏差（详见计划量与实际量口径）。
- **报工状态问题**：报工滞后、补报、冲销、重复或漏报造成的当期偏低。
- **认定时点不一致**：完工认定、质检确认或工作包关闭时点不一致造成的口径偏差。

排除以上后仍成立的偏低，才作为生产异常处理。**注意：一次性外部扰动（如设备故障、临时停电、极端天气、检验卡点）经核实后属于"偶发业务异常"，是真实业务事件，不属于非生产性差异，只是不构成持续趋势。**

## 4. 常见误区

1. 把单月一次偏低直接当异常结论，不看偏差幅度、影响与独立佐证。
2. 反过来把"必须持续多月"当成异常成立的必要条件，漏掉单期重大偏差需立即上报的情况。
3. 多工序同时偏离时孤立地各判各的原因，或反过来直接断定同源/传导——应联合核查、不下因果结论。
4. 不先排除非生产性差异（口径/计划/报工/认定时点），把这类偏低误报为生产异常。
5. 把一次性外部扰动当成数据假象排除掉——它是真实业务事件，只是不构成持续趋势。
6. 拿 risk_level 当独立佐证——它与完成率异常同源，不增加证据独立性。
