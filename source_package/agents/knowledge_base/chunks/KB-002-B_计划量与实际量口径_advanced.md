进阶层不只是"把计划量和实际量并列对比"，而是**判断这个对比本身成不成立、能得出什么结论**。计划量与实际量看似简单，跨周期、跨口径时最容易出现"数字对得上、口径对不上"的陷阱。

## 1. 对比成立的前提

计划量与实际量的对比要有意义，必须对应同一对象范围、同一分析粒度、同一统计周期，并采用一致的计量单位和完工认定口径。任一对比条件不满足时，该差额不能直接解释为真实进度差异，应先完成口径核验，再谈对比结果。

## 2. 常见口径陷阱

- **累计与单期错配**：累计计划只能与同期累计实际比较，当期计划只能与当期实际比较。混用会得到虚高或虚低的欠产。
- **计划版本错配**：应明确使用原始批准基线还是当前有效计划，并记录计划版本及生效时间。原始基线用于评价原计划兑现，当前有效计划用于评价现行调度执行——两种计划回答的问题不同，不能混用。
- **计划对象范围变化**：任务新增、取消、拆分或合并后，即使船号、工序、月份一致，也未必是同一批生产对象。应核对计划量与实际量覆盖的工作包、托盘或其他生产对象是否一致。
- **工序不可比**：不同工序的数量含义和计量单位可能不同。可以比较各自的计划兑现率，但不能直接比较绝对计划量、实际量、数量差额，也不能据此比较工作量、资源负荷或业务影响。
- **报工口径错位**：异常差额应核验报工截止时间、完工认定状态、补报、冲销及重复记录，同时排查真实生产异常——两方面并列核查，不预设数据必有错。

## 3. 结论分层

基于计划量与实际量两个字段，数据可以直接支持：

- 某对象在某周期的计划与实际是否对齐、差额多少；
- 按维度分组后，哪个对象的计划兑现最好或最差。

数据通常不能单独支持：

- **欠产原因**：欠产是产能、物资、计划还是报工问题，需其他字段或现场证据；
- **计划合理性**：计划定得高还是低，需结合产能基线与历史，不能只看单期差额；
- **责任归属**：需核验设计、物资、前序交付等条件。

因此进阶结论应写成"计划与实际的差额及其口径是否可靠"，而不是直接下"某方产能不足"或"计划不合理"的判断。

## 4. 常见误区

1. 不核对对象范围/粒度/周期/计量口径，直接把计划差额当真实欠产。
2. 用累计计划对比单期实际，或反之，得出虚高欠产。
3. 忽略计划版本，混用原始基线与当前有效计划做对比。
4. 计划对象经拆分/合并后，未核对两个量覆盖的生产对象是否一致。
5. 跨工序直接比较绝对数量差额，忽略工序数量与计量单位不可比。
6. 见到异常差额直接归因，不先中性核验报工口径与真实异常两方面。
