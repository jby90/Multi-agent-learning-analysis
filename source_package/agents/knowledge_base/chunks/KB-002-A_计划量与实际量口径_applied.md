基础层能区分计划量与实际量两个口径；应用层要把它们**并列起来做对比**，回答"计划定了多少、实际做了多少、差在哪里"。单看一个量不够，管理决策需要两个量一起看。

## 1. 计划-完成对比口径

按目标粒度分组后，同时汇总两个量并列展示：

- 计划量：汇总 plan_qty，代表排产系统下达的应完成量；
- 实际量：汇总 actual_qty，代表车间实际报工的完成量；
- 计划差额：计划量减实际量，正值表示欠产、负值表示超计划。

**对比成立的条件**：计划量与实际量应对应同一对象范围、同一分析粒度、同一统计周期，并采用一致的计量单位和完工认定口径。任一条不满足，计划差额就不能直接解释为真实进度差异。

**基础核算粒度**建议采用"船号×工序×月份"；按船号、工序或月份汇总分析时，其他维度必须固定，或确认相关数据可以直接汇总。

## 2. 按维度分组对比

计划-完成对比通常带一个分组维度：

- **按船号**：在同一月份、同一工序、同一计量口径下，可按船号比较计划兑现情况，用于横向排名；不同船处于不同阶段时，不能直接比较绝对计划差额。
- **按工序**：优先比较各工序自身的完成率或偏差率；只有计量单位和工作量含义一致时，才能比较绝对差额。不同工序（预处理、制作托盘、安装托盘）的数量含义可能不同。
- **按月份**：看同一对象逐月的计划兑现走势。

分组后，计划量与实际量并列，再辅以计划差额，就能定位"谁欠产、欠多少"——但须先确认上述分组的可比前提成立。

## 3. 口径差异的管理含义

计划量与实际量的差异，本身只说明"进度对没对上计划"，不直接说明原因：

- 实际远低于计划：欠产，需核查是产出不足还是计划定得偏高；
- 实际接近或超过计划：进度正常或超前，超出计划时仍应核查计划基线是否偏低；
- 两个量都要看：只报实际量看不出"离目标还差多少"，只报计划量看不出"到底做了没有"。

口径差异是后续完成率、偏差率、风险判级的输入——先把两个量的对比看准，再进入比率分析。

## 4. 常见误区

1. 只查实际量不查计划量，无法判断进度是否达标。
2. 把不同周期或不同工序的计划量与实际量直接相减，粒度不一致导致对比无意义。
3. 把计划量当成实际量（或反之）汇报，这是本领域最高频错误。
4. 只做单个量的分组，不做计划-完成并列，得不出"欠产多少"的结论。
