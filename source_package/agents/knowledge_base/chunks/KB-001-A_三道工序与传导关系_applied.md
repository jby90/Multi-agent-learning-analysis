基础层知道工序顺序和"存在传导"这个事实；应用层要**用数据筛查疑似传导**：按同一船号的工序×月份排列完成率或偏差率序列，筛查上游异常是否在合理时间窗口内与下游异常对应，识别疑似传导。完成率序列只能发现滞后关联，不能证明物量传导本身。

## 1. 传导查证的数据组织

传导分析需要把同一船号的多道工序、连续多个月份放在一起看：

- 分组维度：工序×月份，即每道工序逐月一行；
- 观察量：各工序各月的完成率（或偏差率）；
- 排列方式：按工序物流顺序（上游到下游）纵向排列，按月份横向排列，形成一张工序×月份的对照表。

单看一道工序的一个月，看不出传导；必须把工序链和时间轴一起铺开，才能观察"上游异常与下游异常在时序上是否对应"的形态。

## 2. 时间对应的判读

上游异常反映到下游的时间不固定：

- 上游异常可能在同月或后续月份反映到下游，具体取决于在制缓冲、批量交接和计划衔接；缓冲较少或异常发生较早时，下游可能在同一统计月就受影响，而月度汇总本身也无法精确区分月内的先后。
- 判读时先定位上游明显下滑的月份，再看下游在合理时间窗口内是否出现下滑；上游异常在逻辑时间上领先于下游，才构成"疑似传导"的对应。
- **不预设全项目统一时滞**：应按工序计划衔接、在制缓冲或历史交接记录确定合理核查窗口。在本项目或示例数据中，部分记录表现为约一个月的时序间隔，但这不作为固定传导周期。

## 3. 对应是否成立的判断

看到"上游下滑、下游随后下滑"，不能立刻断定就是传导。要先排除几种情况：

- 下游的下滑可能有它自己的独立原因，与上游无关；
- 两道工序同期都下滑，可能是共同的外部因素（如整体计划调整），不是链式传导；
- 数据口径或统计周期不一致，也会造成"看起来对应"的假象。

因此应用层的结论应写成"上下游完成率序列存在时间对应，疑似传导，需进一步核验"，而不是直接断定"上游导致了下游异常"。

## 4. 常见误区

1. 只看单道工序、单个月，得不出传导判断——传导必须在工序链和时间轴上一起看。
2. 假设传导必然滞后固定月数，忽略缓冲较少时下游可能同月即受影响。
3. 看到上下游都下滑就断定传导，不排除下游独立异常或共同外部因素。
4. 用固定时滞套所有传导，忽略时间窗口取决于工序计划衔接与在制缓冲。
