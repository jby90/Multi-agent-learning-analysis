# 并行协同评测说明

## 评测目的

本系统不以“界面上同时亮起多个 Agent”作为并行证明，而是从同一会话的标准 Agent 事件中复算并行阶段、分支耗时、汇聚结果与质量门状态。评委可在协同视图的“协同效能证据”卡片中现场核验。

## 当前可复算指标

- 实际墙钟时间：fork 到确定性 join 的真实耗时。
- 配对串行估算：同一次执行中所有分支墙钟耗时之和。
- 本轮节省时间：`max(配对串行估算 - 实际墙钟时间, 0)`。
- 本轮并行加速：`配对串行估算 / 实际墙钟时间`。
- 分支成功率：成功分支数 / 全部分支数。
- 最大并发宽度：单个阶段同时启动的最大分支数。

“配对串行估算”与并行执行使用完全相同的输入、证据、模型和供应商状态，因此适合现场展示编排收益；它不是一次独立运行的串行对照实验，界面中已明确标注，避免夸大结论。

## 已纳入证据的并行阶段

1. 三源证据检索：领域知识、业务数据、教学策略并行取证。
2. 三路资源生成：岗位微课、实操任务、分阶测验并行生成。
3. 四维质量审核：事实证据、教学适配、数据安全、表达可读性并行审核，再由确定性规则汇聚。

## 质量基线

正式 50×2 评测结果与 `03_评测报告.md` 保持一致：

- 幻觉率：0%
- 知识覆盖率：100%
- 岗位适配率：100%
- 培养终点到达率：98%

并行耗时与正式质量基线同时展示，用于说明系统优化没有绕过专业审核或降低质量门槛。

## 现场验证步骤

1. 打开 `http://127.0.0.1:18080/`，进入“实操通道”。
2. 选择岗位并完成岗前测评。
3. 点击“打开岗位微课”，等待三路资源生成与四维审核汇聚。
4. 切换到“协同视图”。
5. 查看“协同效能证据”卡片中的本轮加速、各阶段分支数、墙钟时间和成功率。

每次正式模型响应时间可能不同，因此现场数值按本轮标准事件实时生成，不使用预置演示数字。
