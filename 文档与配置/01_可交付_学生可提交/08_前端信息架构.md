# 前端信息架构定稿（当前组件实况）

> 本文只描述 `frontend/src/App.vue`、`ReplayToolbar.vue`、`LivePractice.vue`、`ProfilePanel.vue`、`ProfileComparison.vue`、`ResourcePanel.vue`、`LiveStepGuide.vue` 和 `LearningPath.vue` 当前真实展示。

## 顶部控制区

`ReplayToolbar` 始终展示车间数据状态、产品标题、进入方式、导入/导出和页面查看方式。

- 进入方式：“实操通道”与“会话回放”。
- 页面查看方式：“学员模式”与“协同视图”。
- 无已保存实操会话时默认进入“会话回放”；浏览器中存在实操会话标识时默认进入“实操通道”。
- “协同视图”是实操和回放均可选择的查看方式，不是第三个互斥入口。

## 会话回放

回放载入成功后：

- 单画像展示“岗位画像”“微课 / 实操”和“培养路径”。
- 切换“协同视图”后增加协同消息面板。
- 回放工具提供播放、暂停、前进一步、速度、关键帧与会话选择。
- 至少载入三个不同画像且排除辩论回放后，可切换“单画像 / 三画像”。
- “三画像”页面真实展示岗位背景、岗前测评、知识盲区、岗位微课、实操任务和可用时的下一学习点。
- 支持导入、导出 JSONL 会话记录。

回放载入时显示“正在载入”；失败时显示“回放记录暂不可用”和“未能载入岗位培养记录，请确认本地记录完整后重试。”

## 实操通道

`LivePractice` 的真实流程为：

岗位卡选择 → 岗前测评 → 打开岗位微课 → 领取实操任务 → 数据实操 → 理解核对 → 查看下一步训练或完成。

- 未建立会话时展示三张岗位卡。
- 建立会话后，实操标题右侧唯一重置入口为“重新开始”。
- 岗前测评固定五题，提交按钮为“提交岗前测评”。
- 数据实操提供“输入查询语句”文本框与“运行查询”按钮。
- 自由文本理解核对显示“第 N / 最多 4 轮”、历史问答、“你的判断”文本框和“提交本轮判断”。
- 提交理解核对时显示“正在根据你的回答准备并检查下一步提示…”。
- 完成态显示“训练完成”或后端返回的教学化说明，不显示其他完成按钮。

## 实操周边组件

- 有会话记录后，“岗位画像”展示当前岗位、岗前测评分数、当前档位、知识盲区、资源匹配和难度轨迹。
- 学习资源出现前显示 `LiveStepGuide`；资源出现后显示 `ResourcePanel`。
- `ResourcePanel` 展示岗位微课、实操指南或练习题以及确认可用的数据结果。
- 实操指南按题目目标、开始前提示、操作步骤、完成标准组织；页面显式标出“操作步骤”和“完成标准”。
- “培养路径”展示已完成节点、当前节点及可用时的下一步。
- 切换“协同视图”后，在已有会话记录时增加协同消息面板。

## 当前静态教学化提示

| 场景 | 当前组件文案 |
|---|---|
| 实操入口请求失败 | 实操通道暂时不可用。 |
| 岗前测评提交失败 | 岗前测评暂时无法提交。 |
| 推进失败 | 当前步骤暂时无法继续。 |
| 查询请求失败 | 查询暂时无法执行。 |
| 理解核对提交失败 | 本轮判断暂时无法提交。 |
| 会话恢复失败 | 未能恢复上次训练。 |
| 查询被安全拒绝 | 本题的查询未通过数据安全检查，请调整后重试。 |
| 查询服务不可用 | 服务暂时不可用，请稍后再试。 |
| 通用步骤失败 | 当前步骤暂时无法继续，请稍后再试。 |
| 实操指南不可展示 | 这份实操指南暂时无法展示，请稍后再试。 |

动态教学说明由后端返回后再经过学员文本过滤展示；本文不预写组件中不存在的成功、降维或会话过期文案。
