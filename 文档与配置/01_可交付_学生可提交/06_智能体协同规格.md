# 设计11：诊断、任务与审核规格（当前交付版）

> 对外仍是诊断、知识、任务、验证、审核五个职责智能体。自由文本追问由任务/追问能力组件承担，不作为第六角色。

## 诊断与首题路由

- 诊断读取岗位画像与前测答案，确定知识盲区、当前难度与学习建议。
- 当前领域包在启动时加载并冻结。
- 首题由“首个知识盲区 + 诊断难度 + 当前领域 `diagnostic_template_ids`”唯一确定。
- 当前域未配置知识点或难度时停止匹配，并向学员显示教学化提示；不得退回固定题，不得跨域借用模板。

证据：`agents/domain_config.py:170-212`、`agents/task_agent.py:501-520`、`orchestrator/interactive_session.py:323-340`。

## 真实升降档与策略结论题

- 学员答对后产生 `step_up` 学习动作，系统真实请求下一难度档任务。
- 下一档任务必须重新生成、审核并展示；若已到最高档，直接完成，不伪造任务。
- 学员仍需巩固时按前置关系降一档并生成新的学习内容。
- 结论题先按当前任务生成同档练习，再使用同一学习动作决定进阶或完成。

证据：`agents/task_agent.py:523-553`、`orchestrator/interactive_session.py:360-454,903-939`。

## 任务与四段实操指南

任务由当前领域配置提供题面、查询边界、证据和难度。`practice_guide` 确定性输出：

1. 实操目标
2. 开始前
3. 操作步骤
4. 完成标准

证据：`agents/task_agent.py:600-635`。

## 五条生产路径共享审核

以下五条路径都调用同一生产—审核流程：

1. 个性化讲义
2. 首个训练任务
3. 结论练习
4. 进阶任务
5. 数据结论

共享流程为：产物生成 → 审核 → 自然驳回时生成方依据证据辩护 → 复审 → 放行、重生成或安全停止。正式生产链以真实审核结果驱动。

证据：`orchestrator/review_flow.py:81-129`、`orchestrator/interactive_session.py:299,334,382,431,1106`。

## 自由文本理解核对

- 学员用自由文本说明判断依据，共 2–4 轮。
- 问题只能使用当前领域错因词汇、当前任务题面与完整证据集。
- 本轮诊断误区与下一轮目标误区分离记录，避免重生成时改写诊断结论。
- 同一误区重复未掌握时，后端依据知识库共标关系、岗位责任范围与已探查历史确定下一目标；模型结果不一致时拒绝放行。
- 公开文本门会拒绝工程词、无来源数字和答案泄漏。
- 动态问题也经过审核、辩护、复审；证据引用必须与完整证据集精确一致。
- 未批准问题不展示；第二轮后才可完成，第四轮必须安全收敛。

证据：`agents/follow_up_agent.py:181-359`、`agents/review_agent.py:1095-1166`、`orchestrator/interactive_session.py:584-746`。

## 查询失败与安全边界

安全查询形成真实结果后才进入数据结论审核。可识别失败由 T21 返回学员调整；SQL 未执行时不得形成结果或结论。学员只看到对象、范围、口径等可操作建议。

生成、审核或终态转换出现内部异常时，会话进入 `system_error` 安全终态，清除未完成学习动作。重复点击或重复提交同一轮次不会再次推进状态机；HTTP 层只返回公开的 409 文案，不暴露异常类型、状态编号或规则命中细节。
