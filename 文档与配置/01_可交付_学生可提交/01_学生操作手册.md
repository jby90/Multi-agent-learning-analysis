# 学生操作手册

## 开始训练

1. 从顶部切换到“实操通道”，从计划员、工艺师、班组长中选择与你当前学习目标最接近的岗位。
2. 完成岗前测评。请按自己的真实理解作答，系统会据此安排讲义与练习难度。
3. 查看“岗位画像”，重点关注“知识盲区”和“当前档位”。

## 阅读岗位讲义

- 先看本节目标，再阅读核心概念、示例和常见错误。
- 遇到数据口径时，留意对象、时间范围、工序和统计层级。
- 讲义中的依据可展开查看，帮助你判断结论从哪里来。

## 完成实操任务

每个任务分为四段：

1. 实操目标：明确本次要解决的问题。
2. 开始前：确认对象、范围和统计口径。
3. 操作步骤：按顺序完成查询或判断。
4. 完成标准：逐项检查结果是否完整。

按题目要求输入查询或提交答案。若页面提示未通过数据安全检查，请调整查询后重试；若没有返回数据，请调整查询条件后重试。

## 完成理解核对

提交后，页面可能请你用自己的话说明判断依据。

- 每次只回答当前问题，不必背诵原文。
- 尽量说清“看了哪些数据、怎样比较、为什么得出这个判断”。
- 理解核对共 2–4 轮，页面会显示当前进度。
- 提交后请稍候，系统会根据你的回答准备并检查下一步提示。

## 接下来的学习安排

- 如果理解仍不稳：先回顾更基础的讲解，再重新判断。
- 如果回答正确：进入更高一档的真实训练任务。
- 如果已经到达当前学习目标：查看总结并完成本次训练。

## 常见提示

| 页面提示 | 你可以怎么做 |
|---|---|
| 暂时无法匹配合适的训练任务 | 稍后重试，或重新选择岗位开始训练。 |
| 本题的查询未通过数据安全检查，请调整后重试。 | 检查并调整查询内容。 |
| 本次查询没有返回数据，请调整查询条件后重试。 | 检查对象、时间范围和筛选条件。 |
| 已为你提高一档难度 | 阅读新的任务目标，按四段指引继续。 |
| 未能恢复上次训练。 | 点击“重新开始”，重新选择岗位。 |

## 完成与回看

完成后页面显示“训练完成”。需要重新选择岗位或重新训练时，点击当前实操页顶部的“重新开始”。需要复习时进入“会话回放”，可查看单画像记录或“三画像”岗位对比。
