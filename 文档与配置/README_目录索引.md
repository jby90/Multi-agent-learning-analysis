# 文档与配置目录索引

本目录与当前仓库源码包、Docker 镜像配套。历史文件仍保留 1.1.0 和原协同版本口径；涉及当前创新 A+B 版本时，以第 17、18 项为准。两层用途严格分开：

- `01_可交付_学生可提交/`：可用于学生学习、作品提交、现场演示和评委阅读。
- `02_不可交付_内部材料/`：仅供项目组核验与答辩准备，不得随学生作品提交。

6. 智能体协同规格
7. 智能体定义合规对照表
8. 前端信息架构

10. 源码包 README

16. 同事维护版本选择性合并总结
17. 创新 A+B 版本说明与最终评测
18. 当前项目完整说明

## 不可交付层

1. 答辩问答库
2. 赛题逐条核销扫描表

5. 内部核验记录

学生提交前只取 `01_可交付_学生可提交/`，不要复制 `02_不可交付_内部材料/`。
