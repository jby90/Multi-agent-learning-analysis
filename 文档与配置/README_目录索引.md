# 文档与配置目录索引

本目录与 1.1.0 源码包、Docker 镜像同版。两层用途严格分开：

- `01_可交付_学生可提交/`：可用于学生学习、作品提交、现场演示和评委阅读。
- `02_不可交付_内部材料/`：仅供项目组核验与答辩准备，不得随学生作品提交。

## 可交付层

1. 学生操作手册
2. 演示脚本
3. 评测报告
4. 评测失败案例说明
5. 状态机说明
6. 智能体协同规格
7. 智能体定义合规对照表
8. 前端信息架构
9. 数据反证式追问
10. 源码包 README
11. 三画像完整学情数据样例
12. 数据脱敏规则
13. 并行协同评测说明
14. 已有数据库版本升级说明

## 不可交付层

1. 答辩问答库
2. 赛题逐条核销扫描表
3. 赛题逐句核销对比表
4. P7 评测体系口径
5. 内部核验记录

学生提交前只取 `01_可交付_学生可提交/`，不要复制 `02_不可交付_内部材料/`。
