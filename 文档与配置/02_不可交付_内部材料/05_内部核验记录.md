# 1.1.0 最终交付内部核验记录

> 本文件属于内部材料，不随学生作品提交。
>
> 归档说明：本文件只对应 1.1.0。创新 A+B 冻结版的组合门禁、正式 50×2 和 Docker 终验证据见 `2026-07-29-innovation-ab-final-gate-evidence.md`。

## 代码能力核验

- P1：首题按诊断结果与当前领域配置路由，缺配置时诚实停止。
- P2：答对后真实生成并审核进阶任务，结论题走同一确定性学习策略。
- P3：讲义、首题、结论题、进阶题、数据结论五条生产路径共用审核、说明依据与复审闭环。
- P4：状态机共 21 条转移；查询失败真实返回学员调整，不进入数据结论。
- P5：自由文本理解核对限定 2–4 轮，动态问题逐条绑定证据并全量审核。
- P6：实操指南固定输出“实操目标、开始前、操作步骤、完成标准”四段。

## 正式 50×2 核验

- 两轮各 50 例，每例一次，不续跑、不重试、不换样本。
- Round 1：幻觉率 0/977，覆盖率 10/10，自动适配率 160/160，到达终点 48/50。
- Round 2：幻觉率 0/1024，覆盖率 10/10，自动适配率 166/166，到达终点 50/50。
- E2E-020 与 E2E-027 均为模型输出波动；审核与查询安全门正确停止，未泄漏未批准内容，未执行不安全查询。
- 系统性缺陷归因为 0；P5 动态追问的模型调用不冒充本次正式矩阵覆盖范围。

## 交付边界

- 学生可提交文档与内部材料分层存放。
- 源码包不携带提交号、完整性哈希、邮箱、本机路径或内部发布审计文件。
- 建库数据仅保留 5 个 CSV、数据字典与 MySQL 导入脚本。
- 五条冻结回放不依赖模型缓存。
- Docker 镜像已由当前源码重建，并在容器内完成整条交互链验证。
