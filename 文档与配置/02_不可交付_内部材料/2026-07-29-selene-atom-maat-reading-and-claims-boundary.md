## 二、SELENE：选择性辩论不是固定一次预算

### SELENE-S001：原方法的输入与门控信号

**Source:** PDF pp. 97–98, §3.2, Eq. (1)–(4)

SELENE 的 SDI 首先让多个智能体独立生成候选回答、自报置信度和推理轨迹，并读取回答的 log-likelihood。它计算：

- 多个回答嵌入之间的平均语义分歧 `D`；
- 自报置信度与模型内在似然之间的失配 `M`。

只有 `D` 与 `M` 同时较低时才跳过辩论；任一信号较高则启动有界多轮辩论。因此 SDI 是基于实例不确定性的门控，不是“每事务固定最多一次辩护”。

### SELENE-S002：辩论停止与最终裁决

**Source:** PDF p. 98, §3.3–§3.4, Eq. (5)–(6)

进入辩论后，SELENE 仍允许最多约三轮交互，并用语义分歧变化量进行提前停止。对于复杂案例，EWSC 对多个证据改写或子集执行并行裁决，再以判断稳定性进行加权聚合。

本项目没有实现：

- 多个初始候选回答；
- 自报置信度与 log-likelihood；
- 语义分歧阈值；
- 证据扰动并行裁决；
- EWSC 方差加权。

### SELENE-S003：实验并不证明“少辩论无代价”

**Source:** PDF pp. 98–100, Tables 1–5, §4–§5

论文报告组合系统在 BoolQ、CosmosQA 和内部数据上取得较好的成本—准确率权衡。需要注意：单独看 SDI 跳过案例，token 成本显著下降，但准确率相对完整辩论存在约 0.8–1.5 个百分点下降。论文的整体效果来自 SDI 与 EWSC 的组合，不能只引用“约 50% token 降低”而忽略质量权衡和 EWSC 的贡献。

### SELENE-S004：跨模型与局限

**Source:** PDF pp. 100–103, §7, Appendix A–C

SDI 依赖 logits、置信度校准和验证集阈值。作者明确指出阈值会受模型架构或微调设置影响，复杂或证据密集问题仍可能需要较长辩论。

### 对创新 A 的约束

创新 A 可以安全表述为：

> 受 SELENE“按实例分配协同强度、避免无差别辩论”的原则启发，在本系统审核规则和事务历史可确定的条件下，设计事务级辩护预算与安全退化路径。

不能表述为：

- 实现、复现或改进了 SDI；
- 固定一次预算等价于 SDI 门控；
- 已继承 SELENE 的准确率、校准或 token 降幅；
- 固定桩消融已经证明真实模型成本下降；
- 仅靠减少辩护次数即可无损保持质量。

由论文证据推导出的测试要求：

- A 必须保留预算 0/1/4 敏感性；
- 必须分开报告模型调用次数、最终审核结果和失败率；
- 不能只报告调用下降而隐藏通过率或安全停止变化；
- 正式 live 数据产生前只能主张确定性调用上界，不主张真实 token 节省。

## 三、AToM：适应误区必须与教学效果证据分开

### ATOM-S001：问题设定

**Source:** PDF pp. 1–3, §1–§2

AToM 所在的 AdapT 框架研究教师如何观察学生连续预测，再选择一个带正确标签的教学示例，以提高学生对目标概念的后验信念。学生被建模为拥有未知先验的概念学习者。

这与本项目的共同点只有：下一教学动作应随着此前暴露的错误信念变化。

### ATOM-S002：两阶段概率方法

**Source:** PDF p. 5, §4.1, Eq. (4)–(5)

AToM 包含两个明确步骤：

1. 根据学生历史猜测，对学生先验参数执行最大后验估计；
2. 在估计出的先验下，选择使目标概念后验概率最大化的教学示例。

论文也指出该实现没有主动探索学生类型，未来方法可显式权衡对学生类型的探索与对当前后验的利用。

本项目没有实现：

- Bayesian student；
- 学生先验参数；
- MAP 推断；
- 目标概念后验；
- 教学示例最优选择目标；
- 探索—利用优化。

本项目的离散误区判断和关系选靶只能称为场景化借鉴，不能称为 AToM 实现。

### ATOM-S003：教学效果来自实际实验，而非专家意见

**Source:** PDF pp. 6–8, §5–§6

论文对模拟学生测量目标概念后验学习曲线，对人类学生测量实际猜测正确性，并通过受控实验比较 RANDOM、GPT-4 与 AToM。人类实验中 AToM 和 GPT-4 相对随机选例取得显著改进，但结果受学生类型影响；论文还直接测量学生类型推断准确率。

因此，教学有效性证据来自学生行为和对照实验，不来自专家对路径“看起来合理”的判断。

### ATOM-S004：局限

**Source:** PDF pp. 8–10, §7, §10

论文的教师只能选择示例，学生只能观察；没有覆盖自然语言解释、学生提问等更丰富交互。学生先验类型也是研究者人工实例化，而非从真实教学数据中学习得到。

### 对创新 B 的约束

创新 B 可以安全表述为：

> 受 AToM“根据在线暴露的错误信念调整后续教学动作”的思想启发，使用经结构校验和审计留痕的离散误区判断改变下一轮追问目标。

不能表述为：

- 实现或改进了 AToM；
- 离散误区 ID 等同于学生先验或后验；
- 专业人员认可路径即可证明教学有效；
- 固定桩路由变化已经证明学生学习效果提高。

由论文证据推导出的评价边界：

- 专业人员仅抽检题目、标准答案和证据的专业正确性；
- 专业抽检不是 B 启用硬门禁，不进入算法直接证据；
- B 是否启用由固定桩消融、Review 通过、证据绑定、确定性约束和回归门禁决定；
- 若未来主张教学有效性，必须另做真实学员或受控学习结果实验。

## 四、MAAT：本项目借用边际思想，不继承完整目标和保证

### MAAT-S001：完整框架是质量—多样性两阶段选择

**Source:** PDF pp. 3–4, §IV-A–§IV-C

MAAT 每轮先用 Expected Model Change 从未测试题池中选取 top-`K_C` 高信息候选，再从该候选集里选择对已测试题集合知识覆盖带来最大边际增益的问题。Importance Module 还利用历史作答数据估计知识概念的重要性权重。

因此，MAAT 的 Diversity Module 不是脱离候选质量门单独运行的全题池覆盖算法。

### MAAT-S002：原覆盖函数不是简单去重集合

**Source:** PDF pp. 4–5, Eq. (3)–(9)

论文先讨论二值知识覆盖的不足，随后提出 Importance Weighted Knowledge Coverage：

- 概念具有正的重要性权重；
- 同一概念的覆盖随相关题数量增加而软增长；
- 新增题目的收益随已有覆盖增加而递减；
- 每轮选择使 IWKC 边际增益最大的候选。

本项目的 `covered_relation_points` 是批准关系路由支持点的集合去重，不包含概念重要性权重，也不使用 `cnt/(cnt+1)` 软覆盖。因此它不是 MAAT 的 IWKC。

### MAAT-S003：理论保证具有严格前提

**Source:** PDF pp. 5–6, §IV-E–§IV-F

MAAT 的 `1-1/e` 贪心保证建立在其非负、单调、次模 IWKC 目标及给定集合大小等前提上。B1 更换了覆盖对象、候选约束、零增益处理和提交语义，不能继承该近似保证。

### MAAT-S004：消融和证据口径

**Source:** PDF pp. 7–9, §V, Fig. 3–5, Table IV

MAAT 使用真实教育数据，将质量和知识覆盖分别量化，并通过改变 `K_C` 比较仅质量、仅多样性及两者平衡。论文的结论基于相同数据、模型和评价指标下的受控比较，而不是使用不同随机后续轨迹比较两个策略。

论文研究的是计算机化自适应测试和知识诊断，不是自然语言教学追问，也没有证明覆盖增加等同于学习成绩提高。

### 对创新 B 的约束

创新 B 可以安全表述为：

> 受 MAAT 的边际覆盖与收益递减思想启发，在审核通过、证据绑定、同域和责任范围约束下，对尚未使用的关系支持点执行确定性边际选靶。

不能表述为：

- 实现了 MAAT Diversity Module 或完整 MAAT；
- 本项目 Review 等同于 MAAT Quality Module；
- 支持点去重集合等同于 IWKC；
- 继承 MAAT 的次模性质或 `1-1/e` 近似保证；
- 支持点增加等同于知识掌握或教学效果提高。

由论文证据推导出的消融要求：

- B0/B1 使用完全相同的历史前缀、轮次、诊断结果和 answer-diagnosis 固定桩；
- `covered_relation_points` 只能来自此前真实 Review approve 且已提交的关系追问；
- 只比较第一次策略分叉以及选靶、增益、支持点等直接确定性后果；
- 不比较第一次分叉后的 LLM 随机生成结果；
- 不允许临时关系、任意覆盖集合、修改关系资产或 monkeypatch 制造差异；
- 采用证据必须可以从冻结输入和批准历史独立复算。

## 五、三篇论文对项目计划的联合结论

| 论文 | 可借用思想 | 本项目真实实现对象 | 必须排除的主张 |
|---|---|---|---|
| SELENE | 按实例分配协同强度，避免无差别辩论 | 审核事务级模型辩护预算与确定性安全退化 | 固定一次预算等同于 SDI；继承准确率/token 结果 |
| AToM | 根据在线暴露的误区调整后续教学动作 | 离散诊断误区驱动下一追问目标 | 实现 Bayesian student；专家意见证明教学有效 |
| MAAT | 有限序列中使用边际覆盖抑制重复 | 批准关系路由支持点的集合边际增益 | 实现 IWKC；继承次模保证；覆盖等同学习成绩 |

三篇论文共同支持的是“选择性、适应性和边际收益递减”三个设计原则，而不是本项目具体预算值、离散误区模型或支持点集合算法。项目创新应放在：

```text
论文原则
→ 领域证据和审核规则下的场景化重定义
→ 可复算的确定性控制机制
→ 与原算法严格区分的消融和主张边界
```

## 六、修订后的证据结构

### 6.1 创新 A 直接证据

- 固定桩下事务辩护调用上界；
- 预算 0/1/4 敏感性；
- Review/re-review 完整性；
- 审计失败与关联错误安全停止；
- 白名单反馈和工程信息零泄漏；
- A0/A1-B/A1-F/A1-BF 消融。

### 6.2 创新 B 直接证据

- 冻结且相同的分叉前输入；
- 第一次真实可达策略分叉；
- 分叉的直接确定性后果；
- 批准覆盖来源的可追溯清单；
- Review、证据绑定、同域和责任范围门禁；
- 异常、拒绝和重放零覆盖污染。

专业人员抽检只属于测试题、答案和证据的专业正确性质量记录。

### 6.3 正式三指标证据

正式 50×2 只证明最终组合版本的：

- 幻觉率不回退；
- 适配率不回退；
- 知识覆盖率不回退。

不得写成“证明创新 A/B 有效”或“证明两域整体能力”。

### 6.4 第二域迁移证据

第二域单独以以下证据证明迁移不回退：

- 固定桩完整交互；
- Agent 测试；
- 关系函数的空关系安全退化；
- domain-swap 回归；
- 主域标识零串入；
- B0/B1 公开行为和最终状态观察等价。

第二域证据和正式 50×2 分别报告，不合并成同一结论。

## 七、最终建议

三项计划修订均应采纳：

1. 删除“领域专家确认教学合理性”作为 B 生产启用硬门禁及算法直接证据；
2. 增加 B 消融的同前缀、同轮次、同诊断、同固定桩、批准覆盖来源和首次分叉隔离条件；
3. 正式 50×2 与第二域迁移证据分别执行、分别报告。

这三项修订不是削弱创新，而是让创新主张与原论文的真实证据结构一致，避免把专业正确性、算法确定性和教学有效性混为一谈。
