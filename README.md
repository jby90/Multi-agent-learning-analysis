# 多智能体协同决策系统

本仓库包含船厂数字化岗位培训系统的源码、评测材料，以及面向已安装旧版学生的前后端增量升级镜像。

## 已部署旧版的学生

数据库结构和比赛数据没有变化，不需要重新导入数据库。更新到仓库最新版本后，请按照：

- [已有数据库版本升级说明](Docker镜像/README.md)

手工加载新版后端、前端镜像，并只重建 `backend`、`frontend` 两个服务。升级过程中不要执行 `docker compose down -v`，也不要删除 `database_data` 数据卷。

## 本次升级内容

- 局部并行 DAG：三源证据检索、三路资源生成、四维质量审核。
- 专业审核 Agent 下设证据、教学适配、数据安全和表达校阅四个专项 Agent。
- 新版智能体协同舱、卡通 Agent 状态动效和协同汇聚动画。
- 真实协同效能证据：墙钟耗时、配对串行估算、加速比和分支成功率。
- 正式模型长响应恢复与 600 秒反向代理等待窗口。

## 安全说明

发布镜像从源码构建，不包含模型 Key、数据库密码或机器特定配置。每位学生继续使用自己本机 `Docker镜像/.env` 中的配置，不要将 `.env` 提交到 Git。

源码说明见 [source_package/README.md](source_package/README.md)，比赛交付文档索引见 [文档与配置/README_目录索引.md](文档与配置/README_目录索引.md)。
